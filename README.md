# BMI Calculator

A simple and user-friendly BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript.

## About the Project

This project allows users to calculate their Body Mass Index (BMI) by entering their height and weight. It displays the BMI result along with the corresponding weight category.

## Features

- Calculate BMI using height and weight.
- Display the BMI value.
- Identify the weight category.
- Simple and responsive user interface.
- Easy to use.

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## Technologies Used

- HTML5
- CSS3
- JavaScript
